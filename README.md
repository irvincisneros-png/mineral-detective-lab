# Mineral Detective Lab

An original, browser-based mineral identification virtual lab for secondary science students.

Students investigate an unknown sample by measuring mass and volume, calculating density, and testing luster, hardness, streak and acid reaction. An in-app identification key supports evidence-based identification. There is no timer, login or tracking.

## Run locally

Open `index.html` directly, or run any static web server in this directory.

## Educational scope

The simulation uses standard published mineral properties and familiar laboratory methods. It is an independent classroom resource and does not contain code, visual assets, text or trademarks copied from ExploreLearning Gizmos.
